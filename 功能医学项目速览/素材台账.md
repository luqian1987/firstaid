# 素材台账

收到的检验报告，逐份记：**报告给到了什么、报告没给什么、哪些要用户拍板**。

`板块划分.md` 管「这份稿子排第几」，本表管「这份稿子的料齐不齐」。
两件事不一样：报告收到了，不等于能开写——方法学、参考区间、报告周期
缺哪一样都得先补，**不许拿常识填**（见 `CLAUDE.md` 第二节）。

报告原件放 `input/`，含受检人信息，永不进版本库。本表只记从报告里读到的
**结构性事实**，不记姓名、样本号、送检单位。

### !! 报告内部矛盾：复查周期有两个口径

| 出处 | 原话 |
|---|---|
| 第 20 页「定期监测与检查」 | 「氨基酸谱检测：建议**每年**或根据医生建议进行氨基酸谱检测」 |
| 第 21 页「致客户声明」 | 「我们建议您可考虑**每 1 至 3 个月**进行一次系统评估」 |

**差 4–12 倍，两条都是报告原文，我无权自选。** 第 20 页在正文的健康管理方案里，
更像技术口径；第 21 页在声明页，更像服务话术。

**已拍板（2026-08-27，用户定）：两条都写，分场景并列，各说各的好处，
落点是「怎么选都比不查强」。** `.actnote` 按这个结构写：

- **每年一次**——常态维持期。氨基酸谱反映的是一段时间的营养与代谢底子，
  一年一次足够看出趋势，成本低、好坚持。
- **每 1–3 个月一次**——正在调整期。改了膳食结构、启动干预方案、或处在
  孕期 / 术后 / 治疗期这类代谢快速变化的阶段，短周期才跟得上变化。
- 收口：**两种节奏都成立，差别只在你现在处于哪个阶段；最不划算的是一次都不查。**

### !! 先纠正：这不是一张「复查折扣卡」

我此前按协议名「**复查**权益卡」推断它是「做过主检之后、复查时打折」的凭证，
在稿子里也是这么写的。**手册说明这个理解是错的。**

它是一张**打包卡**：本身就含一次吉早安®八癌早期预警检测，外加保险、检查费报销、
绿通挂号。结构是「**一次检测 ＋ 两头兜底**」——阴性有保险、阳性有报销。
稿子已按手册原文重写。

## 2026-08-28 前列腺癌甲基化：靶点与 cutoff 都留空，理由在这里

用户问：没有报告，是留空、还是按项目内的靶点写、cutoff 按试剂盒推？
**结论：两样都留空。** 这不是保守，是同组八份摆在一起看，根本推不出来。

### 同组八份的判读方式，四种量纲、彼此无规律

| 癌种 | 基因组合 | 判读 |
|---|---|---|
| 肠癌 | Septin9 | 阴性/阳性，另给检测下限（甲基化 DNA 含量 1%） |
| 肺癌 | SHOX2 / RASSF1A / PTGER4 | **P 值** ＜2 阴性 |
| 肝癌 | RNF135 / PAX5 / CHFR | **P 值** ＜0.24 阴性 |
| 胃癌 | RNF180 / Septin9 | **Ct** ＜45 阳｜**ΔCt** ≤9 阳（同报告内两套规则） |
| 食道癌 | MT-1A / Epo / Septin9 | **Ct** ≤37.5（两个基因）｜≤43（第三个） |
| 胰腺 | BNC1 / ZNF154 | **Ct** ≤40.5｜≤41.0 |
| 尿路上皮癌 | Twist1 / Vimentin | **cp 值 + 内参 ACTB**，综合判定 |
| 子宫内膜癌 | CDO1 / AJAP1 / GALR1 | **检测值** 0~0.46 正常 |

两个观察：

1. **同为 P 值，肺癌阈值 2、肝癌 0.24，差了近十倍**；同为 Ct，跨度 37.5–45，
   而且**同一份报告里不同基因的阈值还不一样**。拿任何一个去套前列腺都是瞎猜。
2. **基因组合是各家实验室自己定的**，不是教科书套路——肝癌那组 RNF135/PAX5/CHFR
   就不是通用组合。按「行业常见前列腺甲基化靶点」填，大概率与实际试剂盒对不上。

**错的阈值印在带价格的说明单上，比空着更麻烦**——空着销售会问，错了没人会问。

### 稿子怎么处理的

第 2 节的表改成**「已确定 / 待检验报告样张」两块**：
- **已确定**：样本尿液、方法学实时荧光定量 PCR（同组统一）、结果阴性/阳性、
  多基因判读规则（任一阳性即整体阳性）
- **待补**：检测基因组合、判读阈值——两行，标红

`.dnote` 把上面这张差异表的结论写进去了，所以这一页**读起来是「说明为什么不填」，
不是「这里有个洞」**。其余五节照常写满，版式与另外八份一致。
