# 肿瘤 NGS 平台招标需求（征求意见稿）

以院方另一份《检验医学中心 NGS 平台招标需求》为结构参照，重写的肿瘤方向招标
需求。参照文本中存在若干定向性与合规性问题，本稿逐条改写，并在文中以「拟稿
说明」记录改写依据 —— 那些段落是给院内讨论看的，发文前应整体删除。

## 与参照文本的主要差异

| 参照文本 | 本稿处理 |
| --- | --- |
| 列出意向公司及报价扣率 | 删除。招标文件不得在开标前列示供应商及报价 |
| 应急方案指名某公司实验室 | 改为以资质与能力描述受托机构 |
| 指定三台测序仪品牌型号且「不得更换」 | 改为参数化技术要求，参考型号一律加「或同等」 |
| 科研支持（驻场博士、协助发表文章与标书） | 删除。科研合作应另案另签、经科研管理与伦理审查 |
| 项目推广 | 删除。属供应商商业行为，非采购标的 |
| 派遣持证人员从事湿实验操作 | 改为培训与技术支持，临床检测由院方资质人员承担 |
| 设备无偿投放 + 试剂扣率 | 改为设备买断、所有权归院方；试剂排除在本次采购外，
另行组织采购，同时要求披露平台开放性并提供价格承诺，纳入全生命周期成本评审 |
| 「终身免费维保」 | 改为明确质保年限、响应与到场时限、备机义务 |
| 无数据条款 | 新增数据权属与信息安全、人类遗传资源合规 |
| 无退出机制 | 新增违约与退出交接条款 |

## 文件

| 文件 | 说明 |

| `ngs-tender.html` | 成品，黑白 A4 版式，浏览器可直接打印 |

| `readdoc.py` | 从 OLE2 格式的 .doc 提取正文（本容器 LibreOffice 不可用时的替代手段） |

## 守卫

`build_tender.py` 有三道断言：

1. 页面用到的每个 CSS 变量必须在 `:root` 定义过；
2. 样式表中所有十六进制颜色必须为灰阶；
3. 定向性内容（供应商名称、扣率、意向公司）全文禁止出现；被删条款的名称
   （科研支持、项目推广等）只在正文禁止，「拟稿说明」里需要解释为何删除。

## 已知限制

docx-js 生成段落边框（`w:pBdr`）时按 top→bottom→left→right 排列子元素，与
OOXML 要求的 top→left→bottom→right 冲突，因此同时带上下框线的段落无法通过
schema 校验。本稿的提示框改用单格表格实现（`w:tcBorders` 顺序正确）。

本容器内 LibreOffice 无法启动，Word 版未做渲染视觉复核，仅通过 XML schema
校验与结构回读。
