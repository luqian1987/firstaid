# 肿瘤 NGS 实验室筹建方案 · 现场汇报材料

面向医院方的项目洽谈总结会汇报材料。与本仓库的体检报告判读系统无关，
仅借此分支存放交付物。

## 文件

| 文件 | 说明 |
| --- | --- |
| `ngs-lab.html` | 汇报材料成品，浏览器直接打开即可投屏 |
| `tpl.html` | 页面模板（含全部版式与文案），数据位留 `__STRIP__` 等占位符 |
| `calc.py` | 从《设备配置清单》解析六个功能间的设备构成 → `rooms.json` |
| `calc2.py` | 按《设备尺寸参数》测算各间台面净长与建议面积 → `area.json` |
| `build.py` | 读取两份 xlsx，填充模板，生成 `ngs-lab.html` |

## 重新生成

原始 xlsx 未入库（属客户资料）。将《设备配置清单》与《可开展检测项目与收费》
两份文件放回 `build.py` / `calc.py` 中 `UP`、`SRC` 指向的路径后：

```
pip install openpyxl
python3 calc.py && python3 calc2.py && python3 build.py
```

## 数据口径

- **来自资料**：六个功能分区与 91 项设备（每项 1 台/支）、设备尺寸、
  5 个已注册试剂盒的注册证号与物价。
- **推算值**：各间建议台面净长与建议净使用面积。台面净长 = 该间台式仪器
  实际宽度之和 + 每件 10 cm 操作间距；建议面积在此基础上计入落地设备占位、
  0.75 m 台面进深与 ≥1.2 m 通行净宽。合计 ≥64 ㎡（不含缓冲间）。
- **待确认**：房间实测尺寸、水电暖通承重、清单外必配设备（核酸提取、
  −80 ℃、UPS、样本前处理场地）、资质与验收时间表。收入测算为口径演示，
  未扣成本，不构成承诺。
