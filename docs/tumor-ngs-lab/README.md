# 肿瘤 NGS 实验室落位方案 · 现场汇报材料

面向医院方的项目洽谈总结会汇报材料。与本仓库的体检报告判读系统无关，
仅借此分支存放交付物。

场地为病理科现有空闲 PCR 多分区实验室，六间房及各自缓冲间均已建成，
**不涉及新建与装修改造**——材料只讲功能分配与设备落位。

## 文件

| 文件 | 说明 |
| --- | --- |
| `ngs-lab.html` | 汇报材料成品，浏览器直接打开即可投屏 |
| `tpl2.html` | 页面模板（版式与文案），数据位留 `__PLAN__` 等占位符 |
| `build2.py` | 读取两份 xlsx，生成平面草图 SVG、房间卡、设备表、试剂盒表 |

## 重新生成

原始 xlsx 未入库（属客户资料）。将《设备配置清单》与《可开展检测项目与收费》
放回 `build2.py` 中 `UP` 指向的路径后：

```
pip install openpyxl
python3 build2.py
```

`build2.py` 内置断言：各房间「台面主要设备 + 另含 N 项」之和必须等于清单实际
条数，数据对不上会直接报错，不会生成错页。

## 房间对照

平面草图依据《设备尺寸参数与摆放示意图》第 2 页重绘。该页 PPT 在图纸上叠加了
功能标注，按标注框坐标核对，功能与图纸原有门牌的对应关系是：

| 功能分区 | 房间 | 图纸原门牌 | PPT 叠加标注 |
| --- | --- | --- | --- |
| 试剂准备区 | 试剂准备间 | 试剂准备 | — |
| 标本与文库制备区 | PCR2 | 标本制备 | 样本制备1 |
| 血浆文库制备区 | PCR3 | 文库 | 样本制备2 |
| 杂交捕获区 | PCR4 | **扩增** | 杂交捕获 |
| 文库扩增与检测区 | PCR5 | **捕获** | 扩增 |
| 测序区 | PCR8 | **文库 QC** | 测序 |

后三间的现场门牌与本次功能错位，落位后需更换标识。
