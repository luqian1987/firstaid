# 架构

## 为什么是这个形状

两种做法的差别不在提示词，在数据流向：

```
扇出式（内容生成）：
    指标 → 打箭头 → 归入主题 → 主题挂模板动作 → 用本人数值填槽
    指标之间从不相遇，所以永远发现不了矛盾。

收敛式（二次判读）：
    指标组合 → 识别形态/矛盾 → 生成判读 → 排序
    判断产生在指标的关系上，不在单个指标上。
```

本系统是后者。所有设计取舍都服从一件事：**判断必须产生在指标的关系上，且可回溯。**

## 分层

| 层 | 目录 | 职责 | 关键不变式 |
|---|---|---|---|
| L0 观察 | `model/observation.py` | 全部原始观察，带出处 | 无出处的观察不得进入判读 |
| L1 归一 | `normalize/` | 单位换算、别名解析、区间解析 | 解析不了 → NO_RANGE，绝不猜成正常 |
| L2 派生 | `derive/` | 派生指标 + 与原报告派生值的一致性校验 | 每个派生值带公式与输入 |
| L3 模式 | `patterns/` | 十类推理模式，三态求值 | 缺输入 → INDETERMINATE，不是未命中 |
| L4 组装 | `patterns/engine.py`, `assemble/` | 命中 → 判读链条 → 分章排序 | 不可改变的主线不得进可行动章 |
| L5 审计 | `audit/` | 覆盖率保证 | 异常项无归宿 → 构建失败 |
| L6 表达 | `render/` | 叙述与渲染 | 文本中的数字必须可追溯到 evidence |

## 三条硬约束

**一、判断权归规则，措辞权归叙述器。**
模式触发与算术是确定性代码，可测试、可复现。LLM 只把已认定的事实写顺，
且只能引用规则传给它的数值（`render/narrate.py::verify_citations`）。
绝不让模型决定一个发现是否存在。

**二、原报告的区间和本系统的知识严格分轨。**
`Observation.ref/status` 永远只反映原报告给了什么；本系统补的常用切点走
`advisory_ref/advisory_status`，并记录出处。所以能如实说出
"原报告未给参考区间；常用切点 7.0 kPa 以下无明显纤维化"这两句话。

**三、覆盖率是断言，不是描述。**
每条观察恰好一个归宿：进链条 / 进需纠正 / 已降级 / 建基线 / 已确认良好 /
完整留档 / 登记为边界。异常项落进"未认领"就是构建失败。
这一层会主动暴露知识库缺口——某个异常反复无人认领，说明缺规则，不是数据特殊。

## 十类推理模式

模式是代码 + 测试，规则实例是纯数据。换一组指标不用改代码。

| # | 模式 | 判读形态 |
|---|---|---|
| 1 | `upstream_contradicted` | 上游异常，下游全阴 → 检测可信度存疑 |
| 2 | `corrected_vs_raw` | 校正值正常 → 未校正值的异常由已知混杂解释 |
| 3 | `paired_divergence` | 配对同向背离 → 系统性偏差而非两个独立异常 |
| 4 | `pattern_dissociation` | 单项升高与本该同行的指标脱节 → 指向不同病因 |
| 5 | `layered_exclusion` | 命名发现按层逐一排除 → 可降级 |
| 6 | `isolated_abnormal` | 孤立异常缺乏佐证 |
| 7 | `acute_phase_coherence` | 多个指标共同描述同一良性背景 |
| 8 | `normal_panel_hidden_risk` | 常规组套全正常，但组合提示风险 |
| 9 | `unranged_structural` | 无区间结构性发现 → 不判高低，转比较口径 |
| 10 | `range_kind_caveat` | 拿实验室自有百分位当疾病界值 |

第 10 类是覆盖率审计逼出来的：两项异常反复落进 UNRESOLVED，说明知识库缺规则。
这正是 L5 应有的作用。

## 纵向

"下次比什么"不是文案，是会被持久化的对象。

- `ComparabilityKey = (code, unit, method, device, axis)`，影像与弹性成像标 `device_sensitive`
- 每条判读产出 `ComparisonItem`，汇总成 `ComparisonPlan`
- 下次体检把新观察对到上次的 plan 上，比不了要说清为什么（换设备/换单位/换方法），而不是硬比

v1 只分析单次，但 `Subject → Encounter → Observation` 与 `Timeline` 现在就是一等对象。
单点分析会显式声明"没有既往体检数据，全部结论只是单点"。

## 责任边界（写进类型，不靠自觉）

- `Verdict` 缺 `not_certain` → 构造失败。不写边界的判读不许发布。
- `Correction.contradicting` 为空 → 构造失败。纠正原报告必须引用同一份报告内的反证。
- 纠正的措辞不说"报告错了"，只说"这条建议的依据不成立"；`what_to_do` 落到复测或面诊。
- 分章不变式：`Modifiability.NOT_MODIFIABLE` 的主线不得进"值得重视，也能主动改善"章。
